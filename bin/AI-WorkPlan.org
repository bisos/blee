Improvements found but deliberately NOT made under 1.1 --- carried to [[1.2]].
NONE of these affect the emacs-31 binary's function relative to emacs-30 built by
this same script: buildConfigOptions is identical for both (lines 296 and 316) and
they share the same dependency path. Items 1,2,3,6,7 are efficiency/waste only.
Items 4,5 (and the re-clone noted under 4) are reproducibility and re-run
idempotency --- they fail loudly, and only when the script is re-run. Item 8 is a
property of the binary but is equally absent from emacs-30 here, so not a regression.

1. Native comp is not AOT. Bare =--with-native-compilation= compiled only the ~150
   preloaded .eln; the rest JIT-compile per-user into ~/.emacs.d/eln-cache.
   =--with-native-compilation=aot= would compile all into the system native-lisp dir.
   Matters for a shared /usr/local install and for doom-blee first-run churn ([[3.2]]).
2. No parallel make. =make bootstrap= (line 1450) and =make install= run serially;
   =-j$(nproc)= is the cheapest available speedup.
3. libwebkit2gtk-4.1-dev is installed as a dependency but =--with-xwidgets= is never
   passed, so HAVE_XWIDGETS is undef --- a large dep pulled in for nothing.
   Either pass the option or drop the packages.
4. tree-sitter is cloned from unpinned upstream master (no -b/tag) and =sudo make
   install=-ed into /usr/local; we got the 2026-09-04 "nightly" tag. Non-reproducible,
   which conflicts with the regression-rebuild goal of Stage 4. Pin a tag or use
   Debian's libtree-sitter-dev. Also =git clone= into an existing dir fails on re-run.
5. =vis_postInstall_common= is not idempotent: line 1636 reads
   /usr/local/bin/emacsclient --version but line 1650 renames that file away, so
   re-running -i postInstall without a fresh make install errors out.
6. Dead code: =installedVerify= line 1697 computes local emacsProg and never uses it.
7. =vis_srcEnvSetup_emacs31= delegates to =vis_srcEnvSetup_emacs27= (line 977) ---
   works, but the emacs27-named function is where the Deb 12/13 + libgccjit logic
   lives. Legacy naming to clean up.
8. HAVE_LIBSELINUX is undef while the host kernel is EL8 and files carry SELinux
   contexts. Emacs will not preserve context when rewriting files on the host side.
   Add libselinux1-dev only if Blee edits host-side labelled files.
